# Monday, Reviewed in One Line

Entry for the make.fun bounty
[u-zeroxfive-monday-reviewed-in-one-line-e55de3c1](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1)

`main.py` (Python 3.13, standard library only) writes one funny
one-line review of the entrant's own Monday — one line, 117
characters — to `/output/entry.txt`.

The review is **"Monday gets one star: my alarm snoozed itself,
my inbox reproduced overnight, and lunch was a meeting about
meetings."**

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt`.
